# minecraft-tracker · Minecraft 版本追踪站

定期监测 Minecraft 的版本更新（**正式版 / 快照 / 愚人节快照**），自动下载并对版本 jar 进行"拆包"分析，把全部版本元数据与文件清单展示在 GitHub Pages 上，支持**多选版本同时查看与对比**。

## 在线访问

- 站点地址：`https://xiaowangdeqilin.github.io/minecraft-tracker/`
- 数据更新：GitHub Actions **每 6 小时**自动运行一次

## 功能

| 功能 | 说明 |
| --- | --- |
| 定期监测 | 每 6 小时拉取 Mojang 官方公开版本清单（`version_manifest_v2`） |
| 全版本列表 | 页面列出清单中**全部**版本（正式版 / 快照 / 愚人节 / 旧版），支持类型筛选、搜索与**分页**（每页 25/50/100/500/全部可选） |
| 全量拆包 | **所有版本**均下载并拆包（客户端 + 服务端），记录内部**文件路径、大小、CRC32** 清单 |
| 服务端追踪 | 每个版本同时追踪 server jar，页面可切换 🖥 客户端 / 🗄 服务端查看与对比 |
| 自动拆包更新 | 发现新版本后自动下载拆包并提交数据 |
| 文件内容查看 | 点击清单中的 📄 文件可直接查看其文本内容（JSON / 语言文件 / 配置 / 着色器等，单个 ≤ 4MB，每版本总量 ≤ 20MB） |
| 任意文件在线查看 | **所有文件均可点击查看**：未收录的文件由浏览器直接从 Mojang 官方 CDN 按需下载 jar 并在前端解包（带进度、内存缓存）——图片以 **base64** 直接渲染、音频内嵌播放、`.class` 及其他二进制以**十六进制**查看，文本可自由切换文本/十六进制视图 |
| 内容搜索 | 文件清单支持全量搜索（数万文件），文件内容支持关键字高亮 |
| 多选查看 | 页面上可勾选任意多个版本同时查看详情与文件清单 |
| 亮色 / 暗色主题 | 右上角按钮切换，自动记忆偏好（并跟随系统偏好） |
| 版本对比 | 选中恰好 2 个版本可查看**新增 / 移除 / 变更**的文件差异（客户端 / 服务端均可） |
| 手动补拆 | 在 Actions 页手动触发工作流，填入版本 ID 可补拆任意历史版本；「全量回填」工作流可重新拆包全部版本 |

## 合理使用原则（重要）

本项目**不存储、不转发、不分发任何 Minecraft 游戏文件**：

1. 版本元数据来自 Mojang 官方公开 API；
2. "拆包"仅指在内存中读取 jar 的文件目录结构（路径 / 大小 / CRC32），产物只是几 KB 的清单 JSON；
3. 下载的 jar 用完即弃，不会进入仓库或 Pages；
4. 页面"任意文件在线查看"同样由**用户浏览器直接向 Mojang 官方 CDN** 发起请求并仅在本机内存中解包展示，本站服务器不经手任何游戏文件。

## 目录结构

```
├── index.html                     # GitHub Pages 前端（纯原生 JS，无构建步骤）
├── scripts/
│   └── fetch_versions.py          # 监测 + 拆包 + 文本内容提取脚本
├── data/
│   ├── index.json                 # 全部版本元数据（页面数据源）
│   ├── versions/<id>.json.gz      # 客户端文件清单（gzip）
│   ├── versions/<id>.server.json.gz # 服务端文件清单（gzip）
│   ├── contents/<id>.json.gz      # 客户端文本内容（gzip，懒加载）
│   ├── contents/<id>.server.json.gz # 服务端文本内容（gzip）
│   └── state.json                 # 状态：已知版本 / 拆包记录 / 内容收录记录
└── .github/workflows/
    ├── monitor.yml                # 每 6 小时定时监测 + 部署 Pages
    └── backfill_all.yml           # 手动触发的全量回填（拆包所有历史版本）
```

## 环境变量（脚本可调）

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `TRACK_RELEASES` | 99999 | 自动追踪最近 N 个正式版（默认全部） |
| `TRACK_SNAPSHOTS` | 99999 | 自动追踪最近 N 个快照（默认全部） |
| `BACKFILL_VERSION` | 空 | 手动补拆的版本 ID（逗号分隔） |
| `CONTENTS_ALL` | 0 | 1 = 对所有处理版本提取文本内容 |
| `FORCE_CONTENTS` | 0 | 1 = 为已拆包但缺内容的版本补充内容 |
| `FORCE_REPACK` | 0 | 1 = 强制重新下载 BACKFILL 中的版本 |

愚人节快照（`20w14∞`、`24w14potato`、`25w14craftmine` 等）始终全量追踪。
